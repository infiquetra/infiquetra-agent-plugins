# staffing U1 — Add the implementation work shape at Claude opus/medium and resolve every tier through one resolver

### Objective

Move saga's builder off Claude Sonnet by giving it its own work shape, and make admission, `/plan`
and `/work` all answer "what tier does this role or unit run at" through one function in fleet-core's
staffing component.

### Intent

**The shape.** Add an `implementation` row to `work_shapes` in
`plugins/fleet-core/scripts/fleet_commons/staffing.json` with `default_model: opus`,
`default_effort: medium`, and a rationale naming the work: implementing a settled plan unit,
including its tests. Point `roles.worker.work_shape` at it. Leave `mechanical` at `sonnet/medium`;
the merging and release workers keep it.

**Claude only.** The new shape is declared Claude-only. A role pinned to another vendor that
resolves through it fails loud, naming the vendor, rather than translating `opus` into that vendor's
portable execution class. `execution_classes`, `root_orchestration_profiles` and every non-Claude
row under `vendors` stay byte-identical.

**One resolver.** Today three paths disagree:

- admission's `_resolve_staffing` in `plugins/saga/scripts/admission.py` resolves role, then shape;
- `/plan`'s tier table instructions call `parse_tier_band` and `resolve_tier_for_plan`, which no
  longer exist anywhere in the repository;
- `/work`'s `resolve-build-unit-tier` in `plugins/saga/scripts/lifecycle_state.py` falls back to
  `mechanical`.

Replace them with one staffing function whose precedence is written once: the repository overlay
(`.saga/tier-defaults.json`), then a Jev-applied raise recorded in the run record (written by
staffing U4; absent until then), then the role's or unit's work-shape default. All three callers use
it, and `/work`'s undeclared default becomes `implementation`.

**Dead weight out.** Delete the ordinal cost table (`cost_weights.json`, `cost_weights.py` and its
test). It rates `opus/medium` at 2.67 times `sonnet/medium`, roughly double the real gap, and
nothing outside its own test reads it.

### Risk

high
Every subagent spawn reads this resolver, so a wrong precedence or a vocabulary slip mis-staffs
every run in the fleet.

### Out-of-scope / non-goals

- Retiring mission-control's stamped tier band is staffing U2.
- Jev's tier judgment is staffing U4; this unit only reserves its place in the precedence.
- No change to any non-Claude vendor row or to the portable execution classes.
- No change to the planner, plan reviewer, lens reviewer or functional tester tiers.

  already rejects a stale bundle.

# and re-run against the repaired bytes rather than assumed to hold.

# The four repairs, and what this proof adds for them:
#   * a command the harness killed at the stage deadline is recorded with
#     `timed_out: true` and no `exit_status`. The previous representation was
#     exit_status -1 with a comment claiming no real exit can be -1; subprocess
#     returncode is -N for termination by signal N, so -1 is SIGHUP and the
#     record could not distinguish a deadline kill from a real signal death.
#     Anchors: the timeout path stops recording the command; the validator
#     accepts a command that is both exited and timed out; the validator
#     accepts a command that never says how it ended.
#   * a supplied run directory must be an existing, empty directory inside the
#     workspace -- the parameter added in round 3 to fix the announced-path
#     defect had routed around the freshness guarantee `allocate_run_directory`
#     provides. Anchors: the supplied path is ignored; an occupied directory is
#     accepted; a directory outside the workspace is accepted.
#   * the `command` == `commands[0].command` alias is checked whenever both are
#     present, including on blocked stages, which round 3 made carry `commands`.
#     Anchor: the alias check is neutralized.
#   * the cycle-13 header overstated its escaped-descendant test: it said the
#     test "confirms the descendant really does survive" while the test wrote a
#     marker it never read -- survival had been observed only by an uncommitted
#     manual probe. Per this repository's convention a published proof is not
#     rewritten to say something more convenient: the overstatement stays in
#     cycle 13 with a dated correction note beside it, and the test now waits
#     for the marker, so from this cycle on the survival claim is checkable.
#     That note is the one edit cycle 13 carries, and it weakens the file's
#     claim rather than strengthening it.
#
# The repair session also disclosed, and deliberately did not repair, one
# defect outside the four findings: a stage whose *later* argv is missing from
# PATH returns a blocked outcome carrying only `command`, dropping the
# per-command statuses and transcript already accumulated from the argvs that
# ran -- the same second-home shape. It is disclosed to the next review rather
# than silently expanded into this bounded round.
#
# Standing disclosures carried forward: MutationProofBindingTest is excluded
# from grading entirely (every mutation edits a graded file, so counting its
# failure as a kill made every mutation a kill by construction, which is what
# made cycle 11 vacuous); the proof cannot start from a fully green suite
# because this run computes the digests that test asserts; "0 survivors" means
# every listed guard is tested, never that the code is correct -- cycle 12 ran
# 51/0 on a revision that then produced three confirmed P1 findings, and cycle
# 13 ran 55/0 on a revision that produced these four P2s.

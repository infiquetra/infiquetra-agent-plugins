### Objective

Build the operator-facing surface: a portable Agent Skill entrypoint that starts the
`voice` pane, the pane itself showing what is bound and what is recording, the stop and
toggle controls, and the preflight that names a missing prerequisite instead of failing
at first use.

**Unit U6 · lane G3 · depends on U1, U2 (identity), U3 (stop playback), U4 (indicator, barge-in).**
**Requirements owned: R4, R8, R9, R11, R13, R14, R15, R22.** These requirements belong to this unit alone; no
other unit in the run implements them.

Parent contract: infiquetra/infiquetra-agent-plugins#27

### Intent

**Portable runnable surface — the smallest legitimate one.** The accepted ideation
holds that runnable portable behaviour must be reached through an Agent Skill or a
Model Context Protocol server, and version one rejects a listening MCP tool outright.
So the entrypoint is a portable Agent Skill at `plugins/voice/skills/voice/SKILL.md`
plus its bundled CLI at `plugins/voice/scripts/voice_cli.py`. That layout matches
`plugins/unifi/skills/` and `plugins/mission-control/skills/`, keeps the entrypoint
vendor-neutral per `AGENTS.md`, and gives the installed package a discoverable way to
start the pane. No MCP server is added. Keep it simple: the skill starts the pane and
runs preflight; it is not a second command surface.

`voice` runs in its own pane, because an interactive Claude session owns the pane it
occupies (R13). The bound agent's identity is displayed continuously alongside the
recording state (R4), and while recording the pane shows a loud, unmistakable indicator
(R11).

Playback stops immediately on a key press in the pane (R8), and starting a recording
immediately stops any playback in progress (R9) — barge-in. These are two of the three
stop forms the requirements demand.

The third form is settled by operator decision D4: the operator **will** add the
documented Herdr-wide `voice stop` keybinding. `voice` preflights whether it is present
and reports its absence (R14) but never writes Herdr configuration (R15).

Provider preflight checks a declared endpoint and its stated capabilities before use
and reports a missing or misconfigured prerequisite *by name* rather than failing at
first use (R22). It never substitutes one provider for another (R23).

Both runtime providers are resolved, and preflight proves each one end to end:

**Voice Forge text-to-speech (decision D1).** Resolve `VOICE_FORGE_BASE_URL`; call
`GET /health` and require a **usable backend**, because a healthy process with no
available backend is insufficient; call `GET /v1/audio/voices` and require the
configured `VOICE_FORGE_VOICE_ID` to be present; then `POST /v1/audio/speech` with a
short real phrase and verify the response is non-empty, playable audio. On failure,
report by name and **stop — never substitute another text-to-speech provider.**

**Hermes relay speech-to-text (decision D2).** Call
`GET {VOICE_HERMES_BASE_URL}/api/health` and require healthy — but do **not** read
`auth_required: false` as proof that protected routes accept anonymous requests. It
disables only the external OAuth/cookie gate; the dashboard still requires its rotating
loopback session token, and an anonymous call returns `401`.

Obtain that token in memory from `GET {VOICE_HERMES_BASE_URL}/`
(`window.__HERMES_SESSION_TOKEN__`), then prove `/api/profiles` is callable with the
`X-Hermes-Session-Token` header (HTTP 200) and that `VOICE_HERMES_PROFILE` is present.
Verify the profile resolves `stt.provider` = `xai` **without displaying any credential**;
the transcription response's own `provider` field is the authoritative resolution. Then
`POST /api/audio/transcribe?profile=mimir-engineer` with the same header and a short real
audio sample, requiring `provider` = `xai` and a non-empty expected transcript. Confirm
`voice` never read `auth.json`, stored no bearer, and neither persisted nor logged the
session token. On failure, report by name and **stop — never substitute another
speech-to-text provider and never disable Hermes authentication.**

Preflight reports; it never installs, provisions, or manages a service. Use
`urllib.request` from the standard library for both probes (R31).

This is the largest unit by requirement count. If it proves too large in planning,
split preflight from the pane rather than dropping scope.

**Proportionality.** `voice` is a private, single-user developer plugin — not a
Pentagon system. Prefer the smallest compatible implementation. Standard-library
Python at the repository floor of `>=3.12`, tested with `unittest` (R31). Do not add
enterprise, multi-tenant, internet-scale, high-availability, regulatory, or overly
defensive machinery without an explicit requirement or a demonstrated failure.

Do not relax real boundaries in the name of that smallness: credential handling, shell
execution, filesystem writes, Git operations, privacy and retention, destructive
actions, and production safety all keep their full strength.

**Board ownership.** The coordinator is the sole Operations-board writer. This unit
never writes board state; it produces commits, a pull request, and a typed review
outcome, and the coordinator moves the card.

### Out-of-scope / non-goals

- A Model Context Protocol server or listening tool of any kind.
- Writing Herdr configuration or vendoring Herdr (R15).
- Speech synthesis, recording, transcription, or delivery mechanisms.
- Press-and-hold recording, which version one excludes.
- Installing or configuring any provider on the operator's behalf.

**Shared-surface rule.** This unit writes only the files listed below. If it concludes
it must edit a file owned by another unit, it stops and raises the conflict on the
parent contract rather than editing across the boundary.

### Tests to add or update

- `plugins/voice/tests/test_skill_entrypoint.py` — the Agent Skill exists with valid
  front matter and names the CLI that starts the pane; no MCP server is declared.
- `plugins/voice/tests/test_pane.py` — bound identity and recording state are both
  displayed; the stop key interrupts playback immediately rather than at the end of an
  utterance; starting a recording stops playback first.
- `plugins/voice/tests/test_preflight.py` — a missing provider is reported by name and
  never substituted; a Voice Forge process that is healthy but has **no usable backend**
  fails preflight; a missing `VOICE_FORGE_VOICE_ID` in the voices list fails by name; a
  Hermes profile that does not resolve `stt.provider: xai` fails by name; an anonymous
  relay call is treated as a token-missing condition rather than a healthy result; no
  credential value and no session token is ever read from disk, printed, or logged; an absent Herdr `voice stop` keybinding is reported
  rather than installed; no Herdr configuration file is ever written.

- [ ] The skill has a bundled CLI that starts the pane: `test -f plugins/voice/scripts/voice_cli.py` → exits 0.
- [ ] No Model Context Protocol server is declared anywhere in the package: `grep -ricE "mcpServers|mcp_server|modelcontextprotocol" plugins/voice/` → returns 0.

- [ ] Preflight probes both provider contracts: `grep -cE "/health|/v1/audio/voices|/v1/audio/speech|/api/health|/api/audio/transcribe" plugins/voice/scripts/preflight.py` → returns at least 5.
- [ ] Preflight reads no credential and prints none: `grep -riE "auth\.json|XAI_API_KEY|Bearer " plugins/voice/scripts/preflight.py` → returns no output.
- [ ] Preflight obtains the loopback token in memory and never persists it: `grep -cE "X-Hermes-Session-Token" plugins/voice/scripts/preflight.py` → returns at least 1, and `grep -riE "HERMES_SESSION_TOKEN.*(open\(|write|log|print)" plugins/voice/scripts/preflight.py` → returns no output.
- [ ] Herdr configuration is never written (R15): `grep -ricE "herdr.*config.*write|write.*herdr.*config" plugins/voice/scripts/` → returns 0.

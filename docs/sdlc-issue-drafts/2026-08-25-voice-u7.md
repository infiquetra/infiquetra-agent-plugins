### Objective

Prove the full conversational loop works end to end, record the evidence, finalize
the README's truth statement, and write the run's journal entries.

**Unit U7 · lane G4 · depends on U1, U2, U3, U4, U5, U6.**

other unit in the run implements them.

Parent contract: infiquetra/infiquetra-agent-plugins#27

### Intent

Version one is accepted only when the full loop works, the multi-session silence check
passes, and each safety behaviour has been manually verified (R33). This unit produces
that evidence rather than asserting it.

The loop under test is the product requirement in full: a bound Herdr-managed Claude
session speaks its completed hook response after Markdown cleanup with code blocks
omitted; the operator toggles recording; a hosted provider transcribes; and the text
returns to that same bound session's input box, unsubmitted and editable.

Record each of the eight acceptance examples (AE1–AE8) with what was actually observed,
including AE1's multi-session silence check — with at least two Claude sessions
running, exactly one speaks.

Finalize `plugins/voice/README.md` so it states plainly that the package carries no
provenance manifest and no port descriptor (R30).

**This unit is the sole writer of the engineering journal for this run.** Both journal
files are newest-first inserts, so a second writer would guarantee a conflict and
displace every line anchor below the insertion. Record a `DECISIONS.md` entry for the
provider-declaration contract and a `LEARNINGS.md` entry for anything non-obvious the
run established.

**Proportionality.** `voice` is a private, single-user developer tool. Prefer the
smallest compatible implementation. Standard-library Python at the repository floor
of `>=3.12`, tested with `unittest` (R31). Do not add multi-tenant, high-availability,
regulatory, or over-defensive machinery. Do not relax credential, shell, filesystem,
Git, privacy, destructive-action, or production-safety boundaries.

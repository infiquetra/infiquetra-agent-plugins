### Objective

Create the `voice` package skeleton and the contracts every other unit imports:
the provider declaration model, the closed egress-class set, the stated retention
setting, and the subprocess discipline helper.

This unit owns the package root. Every other unit depends on it and adds files
alongside it; no other unit edits the files listed below.

### Intent

Establish the portable core so the remaining six units have a stable contract to
build against.

The provider contract is the load-bearing piece. `voice` ships no provider
implementations (R20, R24). The operator declares each provider with its invocation
or endpoint, its capabilities, its egress class, and the *name* of any credential
environment variable it needs — never the value. A provider that is unavailable
produces a named refusal; substitution is never silent (R23).

The package is portable core plus a Claude client adapter, with hooks confined to the
adapter (R29). It carries no provenance manifest and no port descriptor, because it is
authored here and has no upstream to pin, and the README says so plainly rather than
letting absence carry the meaning (R30).

Every subprocess the package starts closes standard input explicitly and attaches a
deadline (R32). This is a safety requirement carried from the engineering journal, not
ceremony.

**Proportionality.** `voice` is a private, single-user developer tool. Prefer the
smallest compatible implementation. Standard-library Python at the repository floor
of `>=3.12`, tested with `unittest` (R31). Do not add multi-tenant, high-availability,
regulatory, or over-defensive machinery. Do not relax credential, shell, filesystem,
Git, privacy, destructive-action, or production-safety boundaries.

### Out-of-scope / non-goals

- Any provider implementation, credential handling, billing, or service lifecycle.
- The `Stop` hook and binding store — U2 owns those.
- Speech synthesis, recording, transcription, delivery, or pane UI.
- Editing `.github/workflows/ci.yml`; the existing `plugins/*/tests` glob already
  collects this package's tests.

**Shared-surface rule.** This unit writes only the files listed below. If it concludes
it must edit a file owned by another unit, it stops and raises the conflict on the
parent contract rather than editing across the boundary.

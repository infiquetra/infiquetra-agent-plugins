### Objective

Return the transcribed text into the bound agent's input box unsubmitted and
editable — and refuse to do so when that agent is blocked on a human decision.

**Unit U5 · lane G3 · depends on U1, U2 (binding target), U4 (transcript).**
**Requirements owned: R16, R17, R18, R19.** These requirements belong to this unit alone; no
other unit in the run implements them.

Parent contract: infiquetra/infiquetra-agent-plugins#27

### Intent

Transcribed text is delivered into the bound agent's input box unsubmitted and
editable (R16), through `herdr agent send-keys`, which types without submitting. The
bound agent is the only permitted delivery target (R17); there is no broadcast, no
fallback target, and no most-recent-speaker inference.

Speech is never an approval channel. When the bound agent is blocked on a permission,
approval, or other human-decision prompt, keystrokes are choices rather than text, so
`voice` refuses to insert or submit and states the refusal audibly (R18). A refused
transcript is retained only transiently until the operator explicitly uses or discards
it; it is never delivered automatically and never queued for automatic delivery (R19).

**Stated residual, carried from the requirements.** The blocked-state check is not
atomic: `voice` checks state and then delivers, and the agent can become blocked in
between. This narrows the exposure rather than eliminating it. Closing it fully would
need a guard inside `herdr agent send-keys`, which belongs to Herdr as a proposed
enhancement — not to `voice` as workaround machinery. Do not build that workaround
here.

**Proportionality.** `voice` is a private, single-user developer tool. Prefer the
smallest compatible implementation. Standard-library Python at the repository floor
of `>=3.12`, tested with `unittest` (R31). Do not add multi-tenant, high-availability,
regulatory, or over-defensive machinery. Do not relax credential, shell, filesystem,
Git, privacy, destructive-action, or production-safety boundaries.

### Out-of-scope / non-goals

- Modifying Herdr or vendoring any part of it (R15).
- Auto-submitting on the operator's behalf under any circumstance.
- Queuing, retrying, or replaying a refused transcript.
- Terminal-input injection of any kind.

### Objective

Ship the Claude client extension at `plugins/voice/com.infiquetra.claude/`: the
`Stop` hook that supplies the completed assistant response, plus the portable binding
store that decides whether this session is the one allowed to speak.

**Unit U2 · lane G2 · depends on U1.**
**Requirements owned: R1, R2, R3.** These requirements belong to this unit alone; no
other unit in the run implements them.

Parent contract: infiquetra/infiquetra-agent-plugins#27

### Intent

The hook ships with the plugin, runs asynchronously so it never stalls a turn, and
compares its own session identifier against the current binding before doing anything
else (R1).

`voice` binds to exactly one Herdr agent, chosen explicitly by the operator, and stays
bound until the operator explicitly changes it — a sticky binding (R2). Only the bound
agent may speak; an unbound session's hook does nothing and produces no sound at all
(R3).

**Client-extension layout, re-derived from this repository and the current Claude
plugin contract — not invented.** The Claude extension root is exactly
`plugins/voice/com.infiquetra.claude/`, matching
`plugins/unifi/com.infiquetra.claude/` and
`plugins/mission-control/com.infiquetra.claude/`, each of which carries its own
`plugin.json` manifest. Claude declares hooks in a `hooks/hooks.json` descriptor at the
plugin root, whose `hooks.Stop[].hooks[]` entries are `{"type":"command","command":…}`
with `${CLAUDE_PLUGIN_ROOT}` resolving the script path — the shape used by the
installed `openai-codex/codex` plugin's own `Stop` hook. Confirm both against the
current Claude plugin contract at preflight before relying on them.

Response text comes from the hook's `last_assistant_message`, never from the screen.
Terminal-output scraping is rejected outright.

The binding store itself is vendor-neutral and lives in portable `scripts/`; only the
hook is Claude-specific, per R29 and `AGENTS.md:52-53`.

The join key is the Claude hook's session identifier matching `agent_session.value` in
`herdr agent list`. Preflight proves this join before planning relies on it.

**Proportionality.** `voice` is a private, single-user developer plugin — not a
Pentagon system. Prefer the smallest compatible implementation. Standard-library
Python at the repository floor of `>=3.12`, tested with `unittest` (R31). Do not add
enterprise, multi-tenant, internet-scale, high-availability, regulatory, or overly
defensive machinery without an explicit requirement or a demonstrated failure.

Do not relax real boundaries in the name of that smallness: credential handling, shell
execution, filesystem writes, Git operations, privacy and retention, destructive
actions, and production safety all keep their full strength.

**Board ownership.** The coordinator is the sole Operations-board writer. This unit
never writes board state; it produces commits, a pull request, and a typed review
outcome, and the coordinator moves the card.

- Speaking the text — U3 owns synthesis.
- Any pane UI, identity display, or Agent Skill entrypoint — U6 owns those.
- `plugins/voice/adapters/**` — that path is wrong and must not be created.
- Adapters for non-Claude clients; version one is Claude-only.
- Writing Herdr configuration, which R15 forbids outright.

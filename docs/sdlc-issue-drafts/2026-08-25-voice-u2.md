### Objective

Ship the Claude client adapter: the `Stop` hook that supplies the completed
assistant response, plus the binding store that decides whether this session is the
one allowed to speak.

**Unit U2 · lane G2 · depends on U1.**
**Requirements owned: R1, R2, R3.** These requirements belong to this unit alone; no
other unit in the run implements them.

Parent contract: infiquetra/infiquetra-agent-plugins#27

### Intent

The hook ships with the plugin, runs asynchronously so it never stalls a turn, and
compares its own session identifier against the current binding before doing anything
else (R1).

`voice` binds to exactly one Herdr agent, chosen explicitly by the operator, and stays
bound until the operator explicitly changes it (R2). Only the bound agent may speak;
an unbound session's hook does nothing and produces no sound at all (R3).

Response text comes from the hook's `last_assistant_message`, never from the screen.
Terminal-output scraping is rejected outright.

Per R29 the hook lives in the Claude adapter, never in portable core. The join key
confirmed against a live session is that the Claude `session_id` a hook receives
appears as `agent_session.value` in `herdr agent list`. The parent contract records
that this confirmation is unarchived; re-confirm it before relying on it.

**Proportionality.** `voice` is a private, single-user developer tool. Prefer the
smallest compatible implementation. Standard-library Python at the repository floor
of `>=3.12`, tested with `unittest` (R31). Do not add multi-tenant, high-availability,
regulatory, or over-defensive machinery. Do not relax credential, shell, filesystem,
Git, privacy, destructive-action, or production-safety boundaries.

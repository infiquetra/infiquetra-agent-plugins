### Objective

Capture the operator's speech on a toggle, transcribe it through the declared hosted
speech-to-text provider, and leave no audio, no transcript log, and no telemetry
behind.

**Unit U4 · lane G2 · depends on U1.**
**Requirements owned: R10, R12, R25, R26, R27.** These requirements belong to this unit alone; no
other unit in the run implements them.

Parent contract: infiquetra/infiquetra-agent-plugins#27

### Intent

Recording is toggled: one press starts, a second press stops (R10). Version one does
not implement press-and-hold, which would require key-release forwarding that is
unverified and deliberately untested.

Nothing is transcribed and nothing is sent until the operator explicitly stops the
recording (R12). An abandoned recording produces no transcription request at all.

Capture is settled by operator decision D3: `/opt/homebrew/bin/ffmpeg` using the macOS
AVFoundation input device. Terminal microphone permission is confirmed during preflight,
not assumed at run time.

Retention is settled by operator decision D5 and is explicitly ephemeral: temporary
audio is deleted immediately after transcription, including when transcription fails
(R25); `voice` keeps no transcript log of its own — the only durable record is the
bound agent's own conversation history after delivery (R26) — and it emits no telemetry
(R27).

**Operator decision D2 remains genuinely pending and is the only open provider
choice.** The exact hosted speech-to-text provider, its credential *variable name*, and
its external egress declaration are not decided. Do not infer, default, or select one.
Build against the U1 declaration contract so any hosted provider drops in, and park the
unit rather than choosing.

**Proportionality.** `voice` is a private, single-user developer plugin — not a
Pentagon system. Prefer the smallest compatible implementation. Standard-library
Python at the repository floor of `>=3.12`, tested with `unittest` (R31). Do not add
enterprise, multi-tenant, internet-scale, high-availability, regulatory, or overly
defensive machinery without an explicit requirement or a demonstrated failure.

Do not relax real boundaries in the name of that smallness: credential handling, shell
execution, filesystem writes, Git operations, privacy and retention, destructive
actions, and production safety all keep their full strength.

**Board ownership.** The coordinator is the sole Operations-board writer. This unit
never writes board state; it produces commits, a pull request, and a typed review
outcome, and the coordinator moves the card.

### Out-of-scope / non-goals

- Choosing the hosted speech-to-text provider; that is pending decision D2.
- Delivering the transcript to the agent — U5 owns delivery and the blocked-state refusal.
- The recording indicator and barge-in behaviour — U6 owns pane presentation.
- Bundling a speech-to-text implementation or managing credentials.
- Continuous listening, wake words, or any background listener.

**Shared-surface rule.** This unit writes only the files listed below. If it concludes
it must edit a file owned by another unit, it stops and raises the conflict on the
parent contract rather than editing across the boundary.

# Engineering journal - infiquetra-agent-plugins

This directory preserves durable repository knowledge across sessions,
maintainers, and coding agents.

| File | Purpose |
|---|---|
| [LEARNINGS.md](LEARNINGS.md) | Empirical findings and generalizable rules |
| [DECISIONS.md](DECISIONS.md) | Repository-scoped tactical decisions and revisit conditions |
| [QUEUED.md](QUEUED.md) | Deferred work with priority and activation triggers |
| [ARCHIVE.md](ARCHIVE.md) | Shipped, rejected, and superseded entries |
| [narratives/](narratives/) | Longer design or migration explanations |
| [audits/](audits/) | Deep reviews and investigation snapshots |

Update the journal when work creates a durable learning, selects between
alternatives, deliberately defers useful work, ships a queued item, rejects an
item, or supersedes prior guidance.

Repository-scoped tactical decisions belong here. Product decisions belong in
the relevant project context repository, and organization-wide policy belongs
in `infiquetra-context-library`.

# Public-safe Infiquetra summary

This repository is maintained by Infiquetra.

## Development guidance

- Use the commands and conventions documented in this repository.
- Keep changes focused and cover changed script or packaging behavior with
  relevant tests.
- Keep portable behavior separate from vendor-specific packaging and runtime
  integration.
- Do not commit secrets, credentials, local environment files, installed plugin
  copies, or agent runtime state.
- Use pull requests for changes after the initial repository bootstrap.

## Internal standards

Infiquetra maintainers also use private organization standards for security,
delivery, and AI-assisted development. Those standards are not copied here
because this repository is public.

When a public contributor needs guidance, maintainers should translate only the
relevant non-sensitive rule into this repository.

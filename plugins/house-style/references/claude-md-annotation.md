Recorded here because `~/.claude` is not a git repository — this is the exact text added to the
Communication & Feedback section of `~/.claude/CLAUDE.md`, so it can be reconstructed if the local

## Exact text

```
**Why these rules live here, not in an output style.** `~/.claude/CLAUDE.md` reaches every subagent a session spawns; an output style reaches only the main thread. Any rule that would leave a subagent's output unreadable to the agent that consumes it — another agent, a lifecycle tool, a downstream review pass — belongs here, not in a style. The test for any future move: does this rule mean anything to an agent whose output is read by another agent? If yes, it stays in `CLAUDE.md`. If it only shapes what a human operator reads directly in the terminal, a style is the right home.
```
